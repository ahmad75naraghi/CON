کانفیگوراتور حرفه‌ای سرور HPE برای وردپرس؛ با شورت‌کد، پنل مدیریت کامل قطعات، پیشنهاد هوشمند و دستیار AI.

== Description ==

نسخه وردپرسی پروژه «کانفیگوراتور حرفه‌ای سرور HPE فالنیک» با ساختار دیتابیس کاملاً یکسان با نسخه مستقل:

* شورت‌کد `[falnic_server_configurator]` برای اجرای اپ در هر برگه/نوشته — فایل‌های CSS/JS فقط در همان صفحه بارگذاری می‌شوند.
* دو مسیر کاربری «راهنمایی» و «حرفه‌ای» با اعتبارسنجی دو لایه (فرانت‌اند و بک‌اند).
* پیشنهاد دقیقاً سه سرور آماده (اقتصادی / مدیریت‌شده / پیشرفته) از جدول Prepared_Server_Offers.
* دستیار هوشمند AI سازگار با سرویس‌های OpenAI-compatible + Quick Reply و Actionهای امن قابل اعمال روی کانفیگ.
* پنل مدیریت کامل: شاسی‌ها، CPU، RAM، هاردها، کنترلرهای RAID، GPU، کارت شبکه، رایزرها، HBA، درایو نوری، پاورها، پیشنهادهای آماده و درخواست‌های پیش‌فاکتور.
* هنگام فعال‌سازی، همه جدول‌ها و ستون‌ها و ایندکس‌ها بررسی و موارد ناقص به‌صورت خودکار ساخته می‌شوند (ساختار ۱:۱ با دامپ اصلی).
* کش پاسخ‌های قطعات با invalidating خودکار پس از هر تغییر در پنل.
* نونس برای همه endpointهای AJAX + محدودیت نرخ برای AI و ثبت پیش‌فاکتور.

== Installation ==

1. پوشه `falnic-server-configurator` را در `wp-content/plugins` قرار دهید.
2. پلاگین را از منوی «افزونه‌ها» فعال کنید؛ در همین لحظه جدول‌ها بررسی/ساخته و جدول‌های خالی با داده اولیه پر می‌شوند.
3. یک برگه بسازید و شورت‌کد `[falnic_server_configurator]` را در آن قرار دهید.
4. از منوی «کانفیگوراتور سرور → تنظیمات» اطلاعات سرویس AI را وارد کنید (اختیاری).

== Frequently Asked Questions ==

= آیا می‌توانم دامپ دیتابیس نسخه مستقل را وارد کنم؟ =

بله؛ نام و ساختار جدول‌ها دقیقاً یکسان است. کافی است dump را در همان دیتابیس وردپرس import کنید؛ پلاگین در اولین فعال‌سازی/بررسی ساختار داده‌ها را تشخیص می‌دهد و دست نمی‌زند.

= اگر جدولی ناقص باشد چه می‌شود؟ =

در فعال‌سازی، به‌روزرسانی پلاگین و از دکمه «بررسی و بازسازی ساختار» در پیشخوان، ستون‌ها و ایندکس‌های ناقص به‌صورت خودکار اضافه می‌شوند.
