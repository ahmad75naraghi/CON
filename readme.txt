کانفیگوراتور حرفه‌ای سرور HPE برای وردپرس؛ با شورت‌کد، پنل مدیریت کامل قطعات، پیشنهاد هوشمند و دستیار AI.

== Description ==

افزونه وردپرس «کانفیگوراتور حرفه‌ای سرور HPE فالنیک»:

* شورت‌کد `[falnic_server_configurator]` برای اجرای اپ در هر برگه/نوشته — فایل‌های CSS/JS فقط در همان صفحه بارگذاری می‌شوند.
* دو مسیر کاربری «راهنمایی» و «حرفه‌ای» با اعتبارسنجی دو لایه (فرانت‌اند و بک‌اند).
* پیشنهاد دقیقاً سه سرور آماده (اقتصادی / مدیریت‌شده / پیشرفته) از جدول Prepared_Server_Offers با نردبان پایدار.
* دستیار هوشمند AI سازگار با سرویس‌های OpenAI-compatible + Quick Reply و Actionهای امن قابل اعمال روی کانفیگ.
* پنل مدیریت کامل: شاسی‌ها، CPU، RAM، هاردها، کنترلرهای RAID، GPU، کارت شبکه، رایزرها، HBA، درایو نوری، پاورها، پیشنهادهای آماده و درخواست‌های پیش‌فاکتور.
* هنگام فعال‌سازی، همه جدول‌ها و ستون‌ها و ایندکس‌ها بررسی و موارد ناقص به‌صورت خودکار ساخته می‌شوند.
* کش پاسخ‌های قطعات با invalidating خودکار پس از هر تغییر در پنل.
* نونس برای همه endpointهای AJAX + محدودیت نرخ برای AI و ثبت پیش‌فاکتور.
* CSS دست‌نویس ایزوله در برابر قالب‌های سنگین؛ بدون CDN و وابستگی runtime خارجی.

مستندات کامل: README.md · راهنمای توسعه: AGENTS.md · تصمیمات معماری: DECISIONS.md

== Installation ==

1. پوشه افزونه را در `wp-content/plugins/falnic-server-configurator` قرار دهید (فایل اصلی: `falnic-server-configurator.php`).
2. پلاگین را از منوی «افزونه‌ها» فعال کنید؛ در همین لحظه جدول‌ها بررسی/ساخته و جدول‌های خالی با داده اولیه پر می‌شوند.
3. یک برگه بسازید و شورت‌کد `[falnic_server_configurator]` را در آن قرار دهید.
4. از منوی «کانفیگوراتور سرور → تنظیمات» اطلاعات سرویس AI را وارد کنید (اختیاری).
5. برای برندینگ، لوگوی سایت را از «ظاهر → سفارشی‌سازی → لوگو» تنظیم کنید.

== Frequently Asked Questions ==

= آیا می‌توانم دامپ SQL کاتالوگ را وارد کنم؟ =

بله؛ نام و ساختار جدول‌ها پایدار است (Chassis، CPUs، …). کافی است dump را در همان دیتابیس وردپرس import کنید؛ پلاگین در اولین فعال‌سازی/بررسی ساختار داده‌های موجود را تشخیص می‌دهد و دوباره seed نمی‌کند.

= اگر جدولی ناقص باشد چه می‌شود؟ =

در فعال‌سازی، به‌روزرسانی پلاگین و از دکمه «بررسی و بازسازی ساختار» در پیشخوان، ستون‌ها و ایندکس‌های ناقص به‌صورت خودکار اضافه می‌شوند.

= با حذف افزونه داده‌ها پاک می‌شوند؟ =

به‌صورت پیش‌فرض خیر. optionها و transientها پاک می‌شوند ولی جدول‌های کاتالوگ و درخواست‌ها می‌مانند. حذف کامل فقط با فعال‌کردن گزینه مربوط در تنظیمات.

= شورت‌کد روی بقیه سایت کندی ایجاد می‌کند؟ =

خیر. CSS و JS فقط وقتی شورت‌کد واقعاً رندر شود enqueue می‌شوند.
